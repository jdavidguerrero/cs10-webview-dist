# CS10 WebView Distribution

Distribución del APK de Android System WebView (build oficial de Google, arm64-v8a) usado para actualizar las terminales Ciontek CS10 vía USB o link/QR, sin depender de Play Store.

- **Paquete:** `com.google.android.webview`
- **Versión:** 107.0.5304.54
- **Arquitectura:** arm64-v8a (con fallback armeabi-v7a)
- **Firma:** Google Inc. (verificada con `apksigner`)

Ver la última release para el link de descarga directa.
